# Golden Winner Contracting LLC

Cinematic single-page website for Golden Winner Contracting LLC — a multidisciplinary construction company established in 2011, based in Dubai, UAE.

## Stack

- **Framework**: Next.js 15 (App Router, TypeScript)
- **Styling**: Tailwind CSS v4
- **3D**: Three.js (tower crane — fixed background)
- **Animation**: GSAP + ScrollTrigger (counters, parallax, timeline)
- **Smooth Scroll**: Lenis
- **Page Transitions**: Framer Motion
- **Icons**: Lucide React
- **Fonts**: Bebas Neue + Inter (Google Fonts)

## Sections

1. **Hero** — Full-screen with Three.js crane, construction site background
2. **About** — 3-layer parallax, GSAP stat counters (14+ years, 21 services, 45+ clients, AED 40M+)
3. **X-Ray Building** — Sticky SVG blueprint cross-section, 6 scroll-triggered floors with MEP pipe drawing
4. **Quality** — 4 full-screen Framer Motion panels (Contractual Precision, Best Practice, Compliance, Satisfaction)
5. **Safety** — ISO 9001 · 14001 · 45001 animated badge cards
6. **Projects Timeline** — Vertical alternating timeline, all 13 projects with values
7. **Clients Marquee** — Dual-row infinite scroll, 45 clients
8. **Contact** — Crane-at-sunset background, contact form with gold shimmer CTA
